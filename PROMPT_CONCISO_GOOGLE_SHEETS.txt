## TAREFA
Você será meu assistente para implementar um **Sistema de Relatório de Manutenção em Google Sheets** que replica a lógica de um aplicativo Android já existente.

## CONTEXTO: O QUE FAZ O SISTEMA?

É um sistema para uma **fábrica que funciona 24 horas com 3 turnos**:
- **Turno 1**: 05:00 - 13:40
- **Turno 2**: 13:20 - 22:00  
- **Turno 3**: 21:30 - 05:20 (cruza meia-noite)

**Operários registram serviços de manutenção** durante seus turnos. Supervisores aprovam os registros. Admins geram relatórios e gerenciam o sistema.

## PROBLEMA CRÍTICO: TURNO 3 CRUZANDO MEIA-NOITE

Um serviço registrado às **02:00 de 22/03** pertence ao **Turno 3 que começou em 21/03**, não ao dia 22/03.

**Solução**: Usar **WorkDate** (Data de Trabalho) = sempre a data de INÍCIO do turno:
- `SE Turno ∈ [1,2]: WorkDate = Dia Atual`
- `SE Turno = 3 E Hora ∈ [21:30, 23:59]: WorkDate = Dia Atual`
- `SE Turno = 3 E Hora ∈ [00:00, 05:20]: WorkDate = Dia Anterior`

## TABELAS NECESSÁRIAS

1. **SERVIÇOS_MANUTENÇÃO**: ID, UUID, USUÁRIO_ID, MÁQUINA, TIPO_SERVIÇO, DESCRIÇÃO, DATA_HORA_REGISTRO, WORK_DATE, TURNO_ID, É_HORA_EXTRA, FOTOS_URL, STATUS_APROVAÇÃO, SUPERVISOR, DATA_APROVAÇÃO, NOTAS, DELETADO

2. **USUÁRIOS**: ID, NOME, EMAIL, TURNO_ID, PERFIL (Operário|Supervisor|Admin), STATUS

3. **MÁQUINAS**: ID, NOME, LINHA_PRODUÇÃO_ID, STATUS, LOCALIZAÇÃO

4. **LINHAS_PRODUÇÃO**: ID, NOME, DESCRIÇÃO

5. **ESTOQUE**: ID, CÓDIGO, DESCRIÇÃO, LOCALIZAÇÃO, QUANTIDADE

## REGRAS DE NEGÓCIO

### Restrição Principal
- Operário SÓ PODE adicionar serviços dentro de seu turno + 1 hora
- Exemplo: Turno 1 (05:00-13:40) pode adicionar até 14:40

### Hora Extra
- Se registrar entre [fim do turno, fim do turno + 1h]: marcar `é_hora_extra = SIM`

### Registrar em Turno Diferente
- Se operário de T1 registra em T2, EXIGIR nota explicativa
- Supervisor deve aprovar

### Overlaps
- 13:20-13:40 (T1 e T2 simultâneos) - permitir seleção manual
- 21:30-22:00 (T2 e T3 simultâneos) - permitir seleção manual

## FUNCIONALIDADES POR TIPO DE USUÁRIO

**OPERÁRIO**:
- Adicionar serviço (máquina, tipo, descrição, fotos)
- Ver serviços do seu turno + próxima 1 hora
- Editar/remover seus próprios serviços
- Gerar PDF de seu turno
- Ver status de aprovação

**SUPERVISOR**:
- Ver TODOS os serviços (sem restrição de turno)
- Aprovar/Rejeitar com notas
- Gerar relatórios consolidados (múltiplos turnos/dias)
- Filtrar por máquina, período, status

**ADMIN**:
- Tudo que Supervisor faz, mais:
- Gerenciar usuários (CRUD)
- Gerenciar máquinas (CRUD)
- Gerenciar estoque (CRUD)
- Ver logs/auditoria

## FILTROS ESPERADOS

```
1. TURNO ATUAL: Serviços do turno actual + 1h (visibilidade)
2. DIA ESPECÍFICO: Selecionar data + turnos (T1/T2/T3)
3. PERÍODO: Data início até data fim (consolidado)
4. MÁQUINA: Dropdown → histórico dessa máquina
5. STATUS: Pendente | Aprovado | Rejeitado
6. BUSCA LIVRE: Por máquina ou descrição
```

## CÁLCULOS AUTOMÁTICOS

**No ato de CRIAR/EDITAR serviço**:
1. `TurnoID`: detectar baseado em hora (com validação de overlap)
2. `WorkDate`: calcular usando regra do Turno 3
3. `É_Hora_Extra`: SIM se (HoraRegistro > HoraFimTurno) AND (HoraRegistro <= HoraFimTurno + 1h)
4. `Timestamp`: hora exata de registro

**Validações**:
- Máquina, tipo, descrição: obrigatórios
- Descrição: mínimo 10 caracteres
- Se turno ≠ turno_do_usuário: nota obrigatória
- Data não pode ser futura
- Bloquear fora do horário permitido

## RELATÓRIOS

**Relatório Diário (PDF por Turno)**:
- Cabeçalho: Data de trabalho, Turno (T1/T2/T3)
- Serviços agrupados por máquina
- Cada serviço: tipo, descrição, fotos (até 3), horário, status
- Rodapé: páginas, data de geração

**Relatório Consolidado**:
- Período selecionado (múltiplos dias/turnos)
- Agrupado por máquina ou por período
- Gráficos de tendências
- Filtrado por status, máquina, tipo

